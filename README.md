# Smart Service Management System

A web-based service management system developed for e-governance centers to simplify citizen service delivery through digital service requests, online token booking, application tracking, and workflow management.

# Technologies Used

- PHP
- MySQL
- HTML
- CSS
- JavaScript

# Key Features

- Citizen service request management
- Online token booking
- Application status tracking
- Service and application management
- Document verification
- Workflow management
- Role-based access for Admin, Manager, Staff, and Citizen

# User Roles

- **Admin** – Manages services, centers, users, and requests
- **Manager** – Manages staff, services, and service requests
- **Staff** – Handles assigned service requests and related operations
- **Citizen** – Books tokens, submits service requests, and tracks application status

# Database

MySQL is used to store and manage citizen service requests, applications, service details, user information, and workflow-related data.

# Project Overview

The system is designed to improve the efficiency of e-governance service delivery by providing a centralized platform for managing citizen requests, service workflows, token bookings, and application tracking.
